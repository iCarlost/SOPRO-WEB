Proceso

Del proyecto nuevo al expediente técnico completo, en seis pasos.

1

Genera reportes técnicos en PDF y Excel para revisión o integración de expediente.

FAQ

Preguntas frecuentes

¿SOPRO funciona sin internet?

Sí. El uso normal de SOPRO es completamente local. Internet solo se utiliza para descargar el instalador o revisar si hay nuevas versiones disponibles.

¿SOPRO requiere licencia o activación?

No. Desde la versión 1.6.0, SOPRO es código abierto bajo licencia MIT. Instálalo, úsalo y compártelo libremente, sin registros ni vigencia.

¿Qué pasa si Windows muestra "Editor desconocido"?

Es una advertencia normal en instaladores no firmados con certificado de código. Selecciona «Más información» y luego «Ejecutar de todas formas» para continuar.

¿Dónde se guardan mis proyectos?

SOPRO trabaja con archivos de base de datos locales (.db) por proyecto. El usuario conserva control total de sus archivos y puede respaldarlos como cualquier otro archivo.

¿SOPRO es compatible con OPUS CMS?

SOPRO tiene una herramienta complementaria de importación para proyectos OPUS CMS 2010 en formato .DBF, que permite migrar proyectos existentes al formato nativo de SOPRO.
