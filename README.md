# SOPRO Web

Página de presentación estática para SOPRO.

## Publicación rápida en GitHub Pages

1. Crea un repositorio público, por ejemplo `sopro-web`.
2. Sube `index.html` a la rama `main`.
3. En GitHub: Settings → Pages.
4. Source: Deploy from a branch.
5. Branch: `main` / root.
6. La página quedará en una URL similar a:
   `https://icarlost.github.io/sopro-web/`

## Descargas

La página consulta automáticamente el último release del repo público:
`iCarlost/SOPRO-Releases`.
